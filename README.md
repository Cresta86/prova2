# Calcolo strutturale

Applicazione React/Vite per il calcolo strutturale e il predimensionamento rapido di intelaiature metalliche.

## Requisiti

- Node.js 18 o superiore
- npm

## Avvio locale

```bash
npm install
npm run dev
```

Poi apri l'indirizzo mostrato dal terminale, di solito:

```text
http://localhost:5173
```

## Build di produzione

```bash
npm run build
```

La build viene generata nella cartella `dist/`.

## Caricamento su GitHub

1. Crea una nuova repository su GitHub.
2. Carica tutti i file e le cartelle contenuti in questo progetto.
3. Non caricare `node_modules/` né `dist/`.
4. Dopo il clone, esegui `npm install` e `npm run dev`.
